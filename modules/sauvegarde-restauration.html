Sauvegarde et restauration

Un fichier a disparu ou une modification a écrasé le bon contenu. Le premier réflexe est de retrouver l’emplacement d’origine et de déterminer l’état recherché. Tu vas choisir où chercher une copie récupérable et vérifier le résultat d’une restauration.

À la fin de ce module, tu sauras

  • repérer les fichiers locaux, synchronisés et stockés sur un partage
  • choisir entre historique des versions, corbeille et sauvegarde
  • lire la liste des versions récupérables dans l’Historique des fichiers
  • préparer une copie avant intervention et contrôler qu’elle se restaure

À vérifier sur place : emplacements autorisés, périmètre de sauvegarde, droits de restauration, délais de conservation et procédure d’escalade à l’UMONS. Protège les fichiers de l’utilisateur en respectant les destinations et les accès prévus.

Je montre

1. Retrouver où sont les données

Demande le chemin ou le lien exact, le compte utilisé et l’heure du dernier état correct. Vérifie si l’utilisateur a ouvert un dossier local, un emplacement OneDrive ou un partage réseau. Deux dossiers appelés « Documents » peuvent renvoyer à deux emplacements différents.

EmplacementOù chercher
Profil localVérifie les dossiers concernés sur le poste, y compris les Téléchargements et les fichiers enregistrés ailleurs. Si un fichier est supprimé, regarde la corbeille de Windows et cherche une copie dans la sauvegarde disponible.
OneDriveSi la sauvegarde des dossiers est activée, Bureau, Documents ou Images peuvent se trouver dans OneDrive. Ouvre le bon compte sur le web pour voir ce qui est arrivé au serveur. Un nuage bleu signale un fichier disponible en ligne uniquement.
Partage réseauRelève le chemin partagé, par exemple \\serveur-test\dossier. Vérifie les versions précédentes uniquement si le serveur les expose. Si nécessaire, transmets le chemin, l’heure et le fichier demandé à l’équipe qui gère le partage.

2. OneDrive : fichier écrasé ou supprimé

Fichier présent, contenu écrasé

  1. Dans OneDrive sur le web, sélectionne le fichier puis ouvre Historique des versions.
  2. Repère la version d’après l’heure et le contenu attendu. Dans un cas réel, préserve d’abord l’état courant si une modification récente doit être conservée.
  3. Dans le menu de la version voulue, choisis Restaurer. Elle devient la version courante. Microsoft indique que l’ancienne version courante reste dans l’historique. Rouvre le fichier et contrôle son contenu.

Fichier absent

Si l’élément se trouvait dans OneDrive, ouvre sa Corbeille sur le web, retrouve l’élément puis choisis Restaurer. Un fichier en ligne uniquement supprimé depuis le cloud peut être absent de la corbeille de Windows. Si c’est un fichier partagé par quelqu’un d’autre, identifie son emplacement et son propriétaire avant d’escalader.

La présence et la durée de conservation des versions et des éléments supprimés dépendent du compte et des paramètres. Vérifie ce qui est disponible dans le bon espace avant d’annoncer une récupération. Sur un poste avec des modifications encore en attente, préserve ces données avant de relancer une synchronisation.

Microsoft : Restaurer une version précédente · Récupérer des fichiers supprimés de OneDrive · Icônes et états de OneDrive.

3. Historique des fichiers sous Windows

Quand il est activé, l’Historique des fichiers enregistre des versions de fichiers et dossiers couverts sur un lecteur externe ou un emplacement réseau. Vérifie que le dossier était couvert, que la sauvegarde existait avant l’incident et que sa destination est disponible.

Dans l’Explorateur, remonte au dossier d’origine. Pour un fichier supprimé, sélectionne son dossier parent, puis ouvre Restaurer les versions précédentes. Choisis une version qui précède l’incident. Ouvre-la pour contrôler le contenu, ou utilise Restaurer vers… quand l’option est disponible afin de préserver l’état actuel.

Si le fichier était sur un partage, sa liste de versions dépend du serveur et de la configuration du partage. Transmets au responsable de la sauvegarde si la version recherchée n’est pas exposée.

Microsoft : Historique des fichiers de Windows · Versions précédentes sur un partage Windows.

4. Sauvegarder avant d’intervenir

  1. Quoi ? Avec l’utilisateur, recense les fichiers nécessaires et les données locales que l’opération peut toucher : dossiers de travail, fichiers en attente de synchronisation, données d’une application ou archives locales.
  2. Où ? Choisis un emplacement approuvé et distinct de ce qui va être modifié. Note le périmètre, la destination et l’heure dans le ticket, en respectant les règles d’accès.
  3. Comment vérifier ? Contrôle que les données attendues figurent dans la copie. Restaure un échantillon dans un emplacement autorisé, vérifie qu’il s’ouvre et que son contenu correspond. Escalade si une donnée indispensable reste sans copie récupérable.

Comme repère de stratégie, Microsoft documente la règle 3-2-1 et ses extensions : trois copies au total, réparties sur deux types de stockage, dont une hors site. En support, vérifie surtout quel point de restauration est récupérable et qui peut l’utiliser.

Microsoft : Dossiers sauvegardés avec OneDrive · Stratégie Azure Backup et vérification d’une restauration.

On fait ensemble

Labo guidé : récupérer une version sur ton PC ≈ 30 min

Utilise uniquement un espace OneDrive personnel ou de test et un fichier fictif. Tu peux faire le scénario sur papier si l’historique n’est pas accessible.

  1. Crée un fichier exercice-restauration.txt avec le texte « Version A — à retrouver ». Dépose-le dans un dossier de test OneDrive et vérifie sur le web qu’il s’ouvre.
  2. Sur ton PC, change le texte en « Version B — état courant » et enregistre le fichier. Dans le dossier de test, confirme le remplacement du fichier du même nom si tu le téléverses depuis le navigateur. Si tu utilises le dossier OneDrive synchronisé, attends de voir B sur le web.
  3. Sur le web, ouvre Historique des versions. Si aucune version antérieure n’apparaît, garde les fichiers et passe au scénario papier. Sinon, restaure A.
  4. Rouvre le fichier sur le web. Note quel texte est courant et vérifie que B figure dans l’historique.

Sur papier : l’historique montre A à 10 h 05 et B à 10 h 20. Le bon contenu est celui d’avant 10 h 15. Écris la version à sélectionner, le résultat à contrôler et la trace à laisser dans le ticket.

Voir ce que tu dois constater

A est le contenu courant après restauration. B reste dans l’historique. Sur papier, choisir 10 h 05 puis rouvrir le fichier pour lire « Version A — à retrouver ». Exemple de trace : « Version de 10 h 05 restaurée ; fichier rouvert et contenu attendu confirmé. »

Tu fais seul

Mises en situation

Un fichier OneDrive a disparu

Le document était marqué en ligne uniquement. Il a été supprimé et n’apparaît pas dans la corbeille de Windows. Où regardes-tu ?

Voir la correction

Vérifie le compte et le propriétaire, puis cherche dans la corbeille web de l’emplacement d’origine. Contrôle le nom et le dossier, restaure si tu y es autorisé et confirme que le document s’ouvre. Voir les deux chemins OneDrive.

Un classeur partagé a été écrasé

La version du matin était correcte. Le contenu du soir doit rester disponible pour comparaison. Comment procèdes-tu ?

Voir la correction

Identifie le stockage d’origine. Conserve l’état du soir à l’emplacement autorisé. Consulte l’historique si le document est en ligne ou les versions exposées par le partage. Demande une restauration séparée si l’option existe, puis compare avec l’utilisateur. Voir les emplacements et les versions précédentes.

Un poste doit être réinstallé

Le Bureau et Documents sont visibles dans OneDrive. Les Téléchargements contiennent un dossier de travail et une modification est encore en cours de synchronisation. Que vérifies-tu avant de remettre le poste ?

Voir la correction

Vérifie sur le web l’état des fichiers attendus. Préserve les Téléchargements et la modification encore locale dans un emplacement approuvé. Restaure et ouvre un échantillon, puis note le périmètre, le résultat et ce qui reste à confirmer. Voir la préparation.

  • Avant d’agir : préserver l’état courant et les changements encore locaux.
  • Valider : restaurer et ouvrir un échantillon, puis tracer le résultat.
