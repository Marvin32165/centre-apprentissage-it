Machine par machine

Choisis une machine dans la liste : tu vois toute sa marche, dans l'ordre (préparation, installation, configuration, vérifications). Sans choix, toutes les machines des quatre sites sont affichées. Les pages 1 à 6 restent générales, pour tout le monde. Chaque case cochée est mémorisée.

Guide, pas script

Les étapes disent quoi faire et dans quel ordre. Chaque étape se déplie pour le détail : comment, pourquoi, comment vérifier. Les choix (NLB, noms, valeurs) restent à toi.
