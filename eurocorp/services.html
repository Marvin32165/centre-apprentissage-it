Répartition par site et tailles : voir l'inventaire. Les détails d'installation sont dans tes notes brutes de chaque cours.

1SQL Server pour SharePoint, d'après tes notes

  1. Sur SQL Server : service SQL Server Browser en démarrage automatique.
  2. Classement (collation) Latin1_General_CI_AS_KS_WS : à régler à l'installation de SQL.
  3. Sur l'AD, une seule fois : Add-KdsRootKey -EffectiveTime ((Get-Date).AddHours(-10)).
  4. Créer l'OU GMSA et le groupe GS_GMSA_SQL contenant le serveur SQL.
  5. New-ADServiceAccount GMSA_SQL -DNSHostName … -PrincipalsAllowedToRetrieveManagedPassword GS_GMSA_SQL.
  6. Sur le serveur SQL, donner ce compte aux trois services sauf Browser, puis Apply.

Source : sharepoint/notes/Notes.md (parties 2 et 3). Tes notes s'arrêtent avant l'installation de SharePoint. Elles mélangent deux noms de domaine : dans le labo, ce sera eurocorp.lan.
