Préparer l'hôte Hyper-V

Avant la première VM : réseau virtuel, image parent, convention de nommage. Tout ce qui est fait ici, on ne le refait pas 21 fois.

En bref

Une seule image Windows préparée (sysprep) sert de parent ; chaque VM est un disque différentiel léger. Trois types de commutateurs virtuels séparent l'extérieur, les LAN de sites et les liens isolés.

1Pourquoi cette méthode

Installer Windows 21 fois prend des heures et du disque. Un parent + des différentiels : une installation, des VM qui démarrent en quelques minutes, et un disque qui ne grossit que de ce qui change. Conséquence : ne jamais démarrer ni modifier le parent — tous les différentiels en dépendent.

3Ordre

  1. Créer les commutateurs (1 externe, 4 privés).
  2. Préparer le parent (mises à jour, sysprep, arrêt, lecture seule).
  3. Créer le premier différentiel + VM de test, vérifier le démarrage.
  4. Seulement ensuite, créer les VM d'un site, puis les autres.

Reste à toi : la RAM totale : voir l'inventaire (marge vs 64 Go) avant de créer quoi que ce soit.
