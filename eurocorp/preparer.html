En bref

Une seule image Windows préparée (sysprep) sert de parent ; chaque VM est un disque différentiel léger. Trois types de commutateurs virtuels séparent l'extérieur, les LAN de sites et les liens isolés.

1Pourquoi cette méthode

Installer Windows 21 fois prend des heures et du disque. Un parent + des différentiels : une installation, des VM qui démarrent en quelques minutes, et un disque qui ne grossit que de ce qui change. Conséquence : ne jamais démarrer ni modifier le parent — tous les différentiels en dépendent.

3Ordre

  1. Créer les commutateurs (1 externe, 4 privés).
  2. Préparer le parent (mises à jour, sysprep, arrêt, lecture seule).
  3. Créer le premier différentiel + VM de test, vérifier le démarrage.
  4. Seulement ensuite, créer les VM d'un site, puis les autres.

4Le détail, d'après tes notes Hyper-V et Windows Server

ÉtapeCe que disent tes notes
Créer la VM modèleGénération 2, mémoire dynamique décochée, 2 processeurs (au lieu de tous les cœurs), Windows Server 2025 Standard (Desktop Experience).
Premier démarrageIP fixe, fuseau horaire, IE Enhanced Security Off, Bureau à distance autorisé, Windows Update en « télécharger seulement », pare-feu coupé (lab uniquement), et renommer en dernier car ça redémarre.
Sysprepsysprep.exe : cocher Generalize, arrêt Shutdown, ne pas rallumer. Supprimer la VM (fusion des .avhdx), renommer le .vhdx en sysprep.vhdx, le copier dans C:\PARENT\.
Recréer des VM« Attacher un disque dur virtuel ultérieurement », puis ajouter un disque SCSI de type Differencing dont le parent est le modèle.
En PowerShellNew-VHD -ParentPath … -Differencing, New-VM -Generation 2 -MemoryStartupBytes …, Set-VMMemory -DynamicMemoryEnabled $false. L'outil « Script Hyper-V » de la page Autres outils fait ces commandes pour tout un site.
