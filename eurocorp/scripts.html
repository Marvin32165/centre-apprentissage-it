Scripts

Les scripts du labo

Dans l'ordre où on les lance. Les premiers servent dès que le parent Sysprep est prêt : créer les VM du site, puis régler chaque VM. Chaque script se déplie ; Copier met tout dans le presse-papiers.

À savoir

Ces scripts sont écrits d'après le plan mais n'ont jamais été exécutés. Lance chacun d'abord avec -WhatIf (il affiche ce qu'il ferait sans rien faire), puis sur une seule machine. Aucun mot de passe n'est dans un script : ils sont demandés au lancement.

En bref

Sur l'hôte : 00 commutateurs, 01 VM du site. Dans chaque VM : 02 réseau et nom, 03 domaine. Sur les contrôleurs : 04 à 10. Services : 11 à 14. Linux : 20 à 22. Le dossier du livrable : exercices/eurocorp-lab/06-PowerShell/scripts/.

00Commutateurs virtuels de l'hôte

Où : Sur l'hôte Hyper-V (PowerShell administrateur).

Crée le commutateur externe WAN (salle) et le commutateur privé LAN-<site>. À lancer une fois par hôte.

Voir le script 00-New-EuroCorpSwitches.ps1
00-New-EuroCorpSwitches.ps1
<#
.SYNOPSIS
  Crée les commutateurs virtuels de l'hôte : WAN (externe, vers la salle) et LAN-<site> (privé).
.PARAMETER Site
  BRU, PAR, LON ou BER : l'hôte sur lequel tu es.
.PARAMETER CarteReseau
  Nom de la carte physique branchée sur la salle (Get-NetAdapter).
.EXAMPLE
  .\00-New-EuroCorpSwitches.ps1 -Site BRU -CarteReseau "Ethernet" -WhatIf
#>
[CmdletBinding(SupportsShouldProcess)]
param(
    [Parameter(Mandatory)][ValidateSet('BRU','PAR','LON','BER')][string]$Site,
    [Parameter(Mandatory)][string]$CarteReseau
)
$ErrorActionPreference = 'Stop'
if (-not (Get-NetAdapter -Name $CarteReseau -ErrorAction SilentlyContinue)) {
    throw "Carte '$CarteReseau' introuvable. Noms disponibles : $((Get-NetAdapter).Name -join ', ')"
}
if (-not (Get-VMSwitch -Name 'WAN' -ErrorAction SilentlyContinue)) {
    if ($PSCmdlet.ShouldProcess('WAN', 'Créer le commutateur externe')) {
        # -AllowManagementOS $true garde l'hôte joignable (RDP) pendant que le commutateur prend la carte
        New-VMSwitch -Name 'WAN' -NetAdapterName $CarteReseau -AllowManagementOS $true | Out-Null
    }
} else { Write-Host "WAN existe déjà : ignoré." }
$lan = "LAN-$Site"
if (-not (Get-VMSwitch -Name $lan -ErrorAction SilentlyContinue)) {
    if ($PSCmdlet.ShouldProcess($lan, 'Créer le commutateur privé')) {
        New-VMSwitch -Name $lan -SwitchType Private | Out-Null
    }
} else { Write-Host "$lan existe déjà : ignoré." }
Get-VMSwitch | Format-Table Name, SwitchType

01Créer les VM du site depuis le parent Sysprep

Où : Sur l'hôte Hyper-V, une fois C:\PARENT\TEST-SYSPREP.vhdx prêt.

Crée toutes les VM du site : serveurs Windows en disque différentiel, OPNsense (2 cartes), VM Linux Docker (ISO). Mémoire fixe, vCPU et RAM du plan. Ne démarre rien sans -Demarrer.

Voir le script 01-New-EuroCorpVMs.ps1
01-New-EuroCorpVMs.ps1
<#
.SYNOPSIS
  Crée les VM d'un site à partir du plan EUROCORP (source : data/eurocorp.json).
.DESCRIPTION
  - Serveurs Windows : disque DIFFÉRENTIEL sur le parent généralisé (Sysprep), génération 2.
  - OPNsense : 2 cartes (WAN puis LAN-<site>), disque neuf, démarrage sécurisé désactivé, ISO si fournie.
  - Linux (Docker) : disque neuf, démarrage sécurisé désactivé, ISO si fournie.
  - Clients Windows 11 : ignorés (installation depuis ISO, TPM virtuel) sauf indication contraire plus bas.
  Partout : mémoire dynamique DÉSACTIVÉE, aucun point de contrôle automatique.
  Idempotent : une VM qui existe déjà est ignorée. -WhatIf montre ce qui serait fait.
.EXAMPLE
  .\01-New-EuroCorpVMs.ps1 -Site BRU -WhatIf
  .\01-New-EuroCorpVMs.ps1 -Site PAR -VMRoot D:\VM -OpnsenseIso D:\ISO\OPNsense.iso -LinuxIso D:\ISO\ubuntu-24.04.iso
#>
[CmdletBinding(SupportsShouldProcess)]
param(
    [Parameter(Mandatory)][ValidateSet('BRU','PAR','LON','BER')][string]$Site,
    [string]$Parent = 'C:\PARENT\TEST-SYSPREP.vhdx',
    [string]$VMRoot = 'D:\VM',
    [string]$OpnsenseIso,
    [string]$LinuxIso,
    [string[]]$Seulement,          # limiter à certaines VM (noms du plan)
    [switch]$Demarrer
)
$ErrorActionPreference = 'Stop'

# --- Plan (généré depuis data/eurocorp.json) -------------------------------------------------
$Plan = @(
    @{ Nom='BRU-FW01'; Site='BRU'; Type='FW'; Ip='172.17.10.1'; Gw='172.17.10.1'; RamGo=2; Vcpu=2; DisqueGo=20; Role='OPNsense — hub IPsec' }
    @{ Nom='BRU-DC01'; Site='BRU'; Type='WIN'; Ip='172.17.10.10'; Gw='172.17.10.1'; RamGo=4; Vcpu=2; DisqueGo=60; Role='AD DS + DNS + DHCP (failover)' }
    @{ Nom='BRU-IIS01'; Site='BRU'; Type='WIN'; Ip='172.17.10.21'; Gw='172.17.10.1'; RamGo=4; Vcpu=2; DisqueGo=60; Role='IIS — nœud NLB 1' }
    @{ Nom='BRU-IIS02'; Site='BRU'; Type='WIN'; Ip='172.17.10.22'; Gw='172.17.10.1'; RamGo=4; Vcpu=2; DisqueGo=60; Role='IIS — nœud NLB 2' }
    @{ Nom='BRU-EXCH01'; Site='BRU'; Type='WIN'; Ip='172.17.10.30'; Gw='172.17.10.1'; RamGo=16; Vcpu=4; DisqueGo=200; Role='Exchange Server SE' }
    @{ Nom='BRU-DOCKER01'; Site='BRU'; Type='LINUX'; Ip='172.17.10.40'; Gw='172.17.10.1'; RamGo=4; Vcpu=2; DisqueGo=60; Role='Docker — Zabbix (serveur + web + PostgreSQL)' }
    @{ Nom='BRU-CLT01'; Site='BRU'; Type='CLIENT'; Ip='DHCP'; Gw='172.17.10.1'; RamGo=4; Vcpu=2; DisqueGo=60; Role='Client de test (optionnel)' }
    @{ Nom='PAR-FW01'; Site='PAR'; Type='FW'; Ip='172.17.20.1'; Gw='172.17.20.1'; RamGo=2; Vcpu=2; DisqueGo=20; Role='OPNsense — spoke (VM actuelle : 2-PARIS-OPNSENSE)' }
    @{ Nom='PAR-DC01'; Site='PAR'; Type='WIN'; Ip='172.17.20.10'; Gw='172.17.20.1'; RamGo=4; Vcpu=2; DisqueGo=60; Role='AD DS + DNS + DHCP (failover)' }
    @{ Nom='PAR-SQL01'; Site='PAR'; Type='WIN'; Ip='172.17.20.20'; Gw='172.17.20.1'; RamGo=8; Vcpu=4; DisqueGo=100; Role='SQL Server (base de SharePoint)' }
    @{ Nom='PAR-SP01'; Site='PAR'; Type='WIN'; Ip='172.17.20.21'; Gw='172.17.20.1'; RamGo=12; Vcpu=4; DisqueGo=100; Role='SharePoint Server SE' }
    @{ Nom='PAR-CLT01'; Site='PAR'; Type='CLIENT'; Ip='DHCP'; Gw='172.17.20.1'; RamGo=4; Vcpu=2; DisqueGo=60; Role='Client de test (optionnel)' }
    @{ Nom='LON-FW01'; Site='LON'; Type='FW'; Ip='172.17.30.1'; Gw='172.17.30.1'; RamGo=2; Vcpu=2; DisqueGo=20; Role='OPNsense — spoke' }
    @{ Nom='LON-FS01'; Site='LON'; Type='WIN'; Ip='172.17.30.10'; Gw='172.17.30.1'; RamGo=4; Vcpu=2; DisqueGo=160; Role='File Server (Direction, RH, Finance, IT, Commun)' }
    @{ Nom='LON-DOCKER01'; Site='LON'; Type='LINUX'; Ip='172.17.30.40'; Gw='172.17.30.1'; RamGo=4; Vcpu=2; DisqueGo=40; Role='Docker — Redmine (+ MariaDB, nginx)' }
    @{ Nom='LON-CLT01'; Site='LON'; Type='CLIENT'; Ip='DHCP'; Gw='172.17.30.1'; RamGo=4; Vcpu=2; DisqueGo=60; Role='Client de test (optionnel)' }
    @{ Nom='BER-FW01'; Site='BER'; Type='FW'; Ip='172.17.40.1'; Gw='172.17.40.1'; RamGo=2; Vcpu=2; DisqueGo=20; Role='OPNsense — spoke' }
    @{ Nom='BER-DOCKER01'; Site='BER'; Type='LINUX'; Ip='172.17.40.40'; Gw='172.17.40.1'; RamGo=8; Vcpu=4; DisqueGo=100; Role='Docker — pile Wazuh (indexer, manager, dashboard)' }
    @{ Nom='BER-DOCKER02'; Site='BER'; Type='LINUX'; Ip='172.17.40.41'; Gw='172.17.40.1'; RamGo=8; Vcpu=4; DisqueGo=60; Role='Docker — Greenbone Community Edition' }
    @{ Nom='BER-CLT01'; Site='BER'; Type='CLIENT'; Ip='DHCP'; Gw='172.17.40.1'; RamGo=4; Vcpu=2; DisqueGo=60; Role='Client de test (optionnel)' }
)
# ---------------------------------------------------------------------------------------------

$lan = "LAN-$Site"
foreach ($sw in 'WAN', $lan) {
    if (-not (Get-VMSwitch -Name $sw -ErrorAction SilentlyContinue)) { throw "Commutateur '$sw' absent : lance d'abord 00-New-EuroCorpSwitches.ps1." }
}
if (-not (Test-Path $Parent)) { throw "Parent Sysprep introuvable : $Parent" }
if (-not (Get-Item $Parent).IsReadOnly) { Write-Warning "Le parent n'est pas en lecture seule : Set-ItemProperty '$Parent' -Name IsReadOnly -Value `$true" }

$liste = $Plan | Where-Object { $_.Site -eq $Site }
if ($Seulement) { $liste = $liste | Where-Object { $Seulement -contains $_.Nom } }

foreach ($vm in $liste) {
    $nom = $vm.Nom
    if (Get-VM -Name $nom -ErrorAction SilentlyContinue) { Write-Host "[$nom] existe déjà : ignoré."; continue }
    if ($vm.Type -eq 'CLIENT') { Write-Host "[$nom] client Windows 11 : à créer depuis l'ISO (génération 2, TPM virtuel). Ignoré."; continue }

    $dossier = Join-Path $VMRoot $nom
    $ram = [int64]$vm.RamGo * 1GB
    if (-not $PSCmdlet.ShouldProcess($nom, "Créer la VM ($($vm.Type), $($vm.RamGo) Go, $($vm.Vcpu) vCPU)")) { continue }
    New-Item -ItemType Directory -Path $dossier -Force | Out-Null

    switch ($vm.Type) {
        'WIN' {
            $disque = Join-Path $dossier "$nom.vhdx"
            New-VHD -Path $disque -ParentPath $Parent -Differencing | Out-Null
            New-VM -Name $nom -Generation 2 -MemoryStartupBytes $ram -VHDPath $disque -Path $VMRoot -SwitchName $lan | Out-Null
        }
        'FW' {
            $disque = Join-Path $dossier "$nom.vhdx"
            New-VHD -Path $disque -SizeBytes ([int64]$vm.DisqueGo * 1GB) -Dynamic | Out-Null
            # carte 1 = WAN, carte 2 = LAN : l'ordre fait que OPNsense les voit comme hn0 puis hn1
            New-VM -Name $nom -Generation 2 -MemoryStartupBytes $ram -VHDPath $disque -Path $VMRoot -SwitchName 'WAN' | Out-Null
            Add-VMNetworkAdapter -VMName $nom -SwitchName $lan
            Set-VMFirmware -VMName $nom -EnableSecureBoot Off
            if ($OpnsenseIso) { Add-VMDvdDrive -VMName $nom -Path $OpnsenseIso; Set-VMFirmware -VMName $nom -FirstBootDevice (Get-VMDvdDrive -VMName $nom) }
        }
        'LINUX' {
            $disque = Join-Path $dossier "$nom.vhdx"
            New-VHD -Path $disque -SizeBytes ([int64]$vm.DisqueGo * 1GB) -Dynamic | Out-Null
            New-VM -Name $nom -Generation 2 -MemoryStartupBytes $ram -VHDPath $disque -Path $VMRoot -SwitchName $lan | Out-Null
            Set-VMFirmware -VMName $nom -EnableSecureBoot Off
            if ($LinuxIso) { Add-VMDvdDrive -VMName $nom -Path $LinuxIso; Set-VMFirmware -VMName $nom -FirstBootDevice (Get-VMDvdDrive -VMName $nom) }
        }
    }
    Set-VMMemory -VMName $nom -DynamicMemoryEnabled $false
    Set-VMProcessor -VMName $nom -Count $vm.Vcpu
    Set-VM -Name $nom -AutomaticCheckpointsEnabled $false
    Write-Host "[$nom] créée."
}

if ($Demarrer -and -not $WhatIfPreference) {
    foreach ($vm in $liste) { if ($vm.Type -ne 'CLIENT' -and (Get-VM -Name $vm.Nom -ErrorAction SilentlyContinue).State -eq 'Off') { Start-VM -Name $vm.Nom } }
}
Get-VM | Where-Object { $liste.Nom -contains $_.Name } |
    Format-Table Name, State, @{n='RAM(Go)';e={$_.MemoryStartup/1GB}}, ProcessorCount, @{n='Mém.dyn.';e={(Get-VMMemory -VMName $_.Name).DynamicMemoryEnabled}}

02-Initialize-EuroCorpServer.ps1

.SYNOPSIS
  Premier réglage d'un serveur Windows EUROCORP d'après le plan : IP fixe, passerelle, DNS, IPv6 coupé,
  fuseau horaire, pare-feu coupé (LABORATOIRE SEULEMENT), renommage, redémarrage.

.PARAMETER Dns

[CmdletBinding(SupportsShouldProcess)]
param(

    [string[]]$Dns,
    [string]$Carte = 'Ethernet',
    [switch]$GarderPareFeu
)
$ErrorActionPreference = 'Stop'

    @{ Nom='BRU-FW01'; Site='BRU'; Type='FW'; Ip='172.17.10.1'; Gw='172.17.10.1'; RamGo=2; Vcpu=2; DisqueGo=20; Role='OPNsense — hub IPsec' }

    @{ Nom='BRU-CLT01'; Site='BRU'; Type='CLIENT'; Ip='DHCP'; Gw='172.17.10.1'; RamGo=4; Vcpu=2; DisqueGo=60; Role='Client de test (optionnel)' }

    @{ Nom='PAR-SP01'; Site='PAR'; Type='WIN'; Ip='172.17.20.21'; Gw='172.17.20.1'; RamGo=12; Vcpu=4; DisqueGo=100; Role='SharePoint Server SE' }
    @{ Nom='PAR-CLT01'; Site='PAR'; Type='CLIENT'; Ip='DHCP'; Gw='172.17.20.1'; RamGo=4; Vcpu=2; DisqueGo=60; Role='Client de test (optionnel)' }
    @{ Nom='LON-FW01'; Site='LON'; Type='FW'; Ip='172.17.30.1'; Gw='172.17.30.1'; RamGo=2; Vcpu=2; DisqueGo=20; Role='OPNsense — spoke' }

    @{ Nom='LON-DOCKER01'; Site='LON'; Type='LINUX'; Ip='172.17.30.40'; Gw='172.17.30.1'; RamGo=4; Vcpu=2; DisqueGo=40; Role='Docker — Redmine (+ MariaDB, nginx)' }

    else                         { $Dns = @($dcBru, $dcPar) }

    Get-NetIPAddress -InterfaceAlias $Carte -AddressFamily IPv4 -ErrorAction SilentlyContinue | Where-Object { $_.PrefixOrigin -ne 'WellKnown' } | Remove-NetIPAddress -Confirm:$false -ErrorAction SilentlyContinue

    New-NetIPAddress -InterfaceAlias $Carte -IPAddress $vm.Ip -PrefixLength 24 -DefaultGateway $vm.Gw | Out-Null
    Set-DnsClientServerAddress -InterfaceAlias $Carte -ServerAddresses $Dns
    Disable-NetAdapterBinding -Name $Carte -ComponentID ms_tcpip6
    Set-TimeZone -Id 'Romance Standard Time'           # Bruxelles, Paris, Berlin (Londres : adapter si besoin)
    if (-not $GarderPareFeu) { Set-NetFirewallProfile -Profile Domain,Private,Public -Enabled False }
    # Bureau à distance
    Set-ItemProperty -Path 'HKLM:\System\CurrentControlSet\Control\Terminal Server' -Name fDenyTSConnections -Value 0
    Enable-NetFirewallRule -DisplayGroup 'Remote Desktop' -ErrorAction SilentlyContinue
}

    if ($PSCmdlet.ShouldProcess($Nom, 'Renommer et redémarrer')) { Rename-Computer -NewName $Nom -Restart }
} else { Write-Host "Déjà nommée $Nom." }

03Joindre le domaine

Où : Dans chaque serveur Windows (sauf BRU-DC01), après 02.

Vérifie que le DNS résout le domaine, puis joint eurocorp.lan dans l'UO choisie et redémarre.

Voir le script 03-Join-EuroCorpDomain.ps1
03-Join-EuroCorpDomain.ps1
<#
.SYNOPSIS
  Joint le serveur au domaine EUROCORP. Prérequis : 02-Initialize-EuroCorpServer.ps1 fait, BRU-DC01 en ligne.
.PARAMETER OU
  DN de l'UO de destination (ex. "OU=Serveurs,OU=EuroCorp,DC=eurocorp,DC=lan"). Vide = conteneur Computers.
.EXAMPLE
  .\03-Join-EuroCorpDomain.ps1 -OU "OU=Serveurs,OU=EuroCorp,DC=eurocorp,DC=lan"
#>
[CmdletBinding(SupportsShouldProcess)]
param(
    [string]$Domaine = 'eurocorp.lan',
    [string]$OU
)
$ErrorActionPreference = 'Stop'
if ((Get-CimInstance Win32_ComputerSystem).PartOfDomain) { Write-Host "Déjà dans le domaine."; return }
# Sans la résolution des enregistrements SRV du domaine, Add-Computer échoue : on le vérifie avant.
if (-not (Resolve-DnsName -Name "_ldap._tcp.dc._msdcs.$Domaine" -Type SRV -ErrorAction SilentlyContinue)) {
    throw "Le DNS ne résout pas $Domaine : vérifie le DNS de la carte (BRU-DC01 doit répondre) et le tunnel."
}
$cred = Get-Credential -Message "Compte autorisé à joindre des machines au domaine ($Domaine)"
$jonction = @{ DomainName = $Domaine; Credential = $cred; Restart = $true }
if ($OU) { $jonction.OUPath = $OU }
if ($PSCmdlet.ShouldProcess($env:COMPUTERNAME, "Joindre $Domaine")) { Add-Computer @jonction }

04Créer la forêt (BRU-DC01)

Où : Sur BRU-DC01 uniquement, après 02.

Installe AD DS et DNS puis crée la forêt eurocorp.lan. Demande le mot de passe DSRM (à noter dans Infos.md).

Voir le script 04-New-EuroCorpForest.ps1
04-New-EuroCorpForest.ps1
<#
.SYNOPSIS
  Crée la forêt eurocorp.lan sur BRU-DC01 (rôles AD DS + DNS). Le serveur redémarre à la fin.
.EXAMPLE
  .\04-New-EuroCorpForest.ps1 -WhatIf
#>
[CmdletBinding(SupportsShouldProcess)]
param([string]$Domaine = 'eurocorp.lan', [string]$NetBios = 'EUROCORP')
$ErrorActionPreference = 'Stop'
if ($env:COMPUTERNAME -ne 'BRU-DC01') { throw "À lancer sur BRU-DC01 (ici : $env:COMPUTERNAME)." }
$dns = (Get-DnsClientServerAddress -AddressFamily IPv4 | Where-Object { $_.ServerAddresses }).ServerAddresses
Write-Host "DNS de la carte : $($dns -join ', ') (doit être l'IP de BRU-DC01 elle-même)"
if ($PSCmdlet.ShouldProcess($Domaine, 'Installer AD DS + DNS et créer la forêt')) {
    Install-WindowsFeature AD-Domain-Services, DNS -IncludeManagementTools | Out-Null
    $dsrm = Read-Host -AsSecureString "Mot de passe DSRM (restauration des services d'annuaire)"
    Install-ADDSForest -DomainName $Domaine -DomainNetbiosName $NetBios -InstallDns -SafeModeAdministratorPassword $dsrm -Force
}

05Ajouter un contrôleur (PAR-DC01)

Où : Sur PAR-DC01, après 02 et 03, tunnel BRU-PAR monté.

Promeut PAR-DC01 en deuxième contrôleur (DNS inclus), puis repointe son DNS.

Voir le script 05-Add-EuroCorpDomainController.ps1
05-Add-EuroCorpDomainController.ps1
<#
.SYNOPSIS
  Promeut PAR-DC01 en contrôleur de domaine supplémentaire. Prérequis : machine dans le domaine, BRU-DC01 joignable.
.EXAMPLE
  .\05-Add-EuroCorpDomainController.ps1 -Site PAR -WhatIf
#>
[CmdletBinding(SupportsShouldProcess)]
param(
    [string]$Domaine = 'eurocorp.lan',
    [string]$SiteAD = 'Default-First-Site-Name'    # remplacé par PAR après 07-New-EuroCorpAdSites.ps1
)

<#

.PARAMETER Role
  Cible (sur l'hôte de Paris) ou Source (sur l'hôte de Londres).

.EXAMPLE
  .\14-Enable-EuroCorpReplica.ps1 -Role Cible -Auth Kerberos -StockageReplica D:\Replica
  .\14-Enable-EuroCorpReplica.ps1 -Role Source -Auth Kerberos -HoteCible <nom-hôte-Paris>

[CmdletBinding(SupportsShouldProcess)]
param(

            -AuthenticationType $(if ($Auth -eq 'Kerberos') { 'Kerberos' } else { 'Certificate' }) -ReplicationFrequencySec $IntervalleSecondes

20-set-linux-network.sh
#!/usr/bin/env bash
# Réseau d'une VM Linux EUROCORP d'après le plan (source : data/eurocorp.json).
# Usage : sudo ./20-set-linux-network.sh BRU-DOCKER01 [interface]
set -euo pipefail
NOM="${1:?Usage: $0 <NOM-DU-PLAN> [interface]}"
IFACE="${2:-$(ip -o -4 route show to default | awk '{print $5}' | head -1)}"
IFACE="${IFACE:-$(ls /sys/class/net | grep -v '^lo$' | head -1)}"
case "$NOM" in
    BRU-DOCKER01) IP=172.17.10.40; GW=172.17.10.1 ;;
    LON-DOCKER01) IP=172.17.30.40; GW=172.17.30.1 ;;
    BER-DOCKER01) IP=172.17.40.40; GW=172.17.40.1 ;;
    BER-DOCKER02) IP=172.17.40.41; GW=172.17.40.1 ;;
    *) echo "Nom inconnu : $NOM" >&2; exit 1 ;;
esac
DNS1=172.17.10.10; DNS2=172.17.20.10; DOMAINE=eurocorp.lan
cat > /etc/netplan/50-eurocorp.yaml <<EOF
network:
  version: 2
  ethernets:
    $IFACE:
      dhcp4: false
      addresses: [$IP/24]
      routes:
        - to: default
          via: $GW
      nameservers:
        addresses: [$DNS1, $DNS2]
        search: [$DOMAINE]
EOF
chmod 600 /etc/netplan/50-eurocorp.yaml
hostnamectl set-hostname "$(echo "$NOM" | tr 'A-Z' 'a-z')"
echo "Écrit : /etc/netplan/50-eurocorp.yaml (interface $IFACE, $IP). Vérifier puis : sudo netplan apply"
echo "Si une ancienne config DHCP existe dans /etc/netplan/, la renommer en .disabled avant d'appliquer."

21-install-docker.sh
#!/usr/bin/env bash
# Installe Docker CE et le plugin Compose depuis le dépôt officiel (Ubuntu / Debian).
# Usage : sudo ./21-install-docker.sh [utilisateur-a-ajouter-au-groupe-docker]
set -euo pipefail
. /etc/os-release
apt-get update
apt-get install -y ca-certificates curl gnupg
install -m 0755 -d /etc/apt/keyrings
curl -fsSL "https://download.docker.com/linux/$ID/gpg" | gpg --dearmor --yes -o /etc/apt/keyrings/docker.gpg
chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/$ID $VERSION_CODENAME stable" > /etc/apt/sources.list.d/docker.list
apt-get update
apt-get install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
systemctl enable --now docker
[ -n "${1:-}" ] && usermod -aG docker "$1" && echo "$1 ajouté au groupe docker (se reconnecter)."
docker compose version
docker run --rm hello-world

#!/usr/bin/env bash
# Heure synchronisée sur le contrôleur de domaine (chrony). Usage : sudo ./22-chrony-dc.sh
set -euo pipefail
apt-get install -y chrony
mkdir -p /etc/chrony/sources.d
echo "server 172.17.10.10 iburst prefer" > /etc/chrony/sources.d/dc.sources
# si des pools Ubuntu injoignables bloquent la sélection : les désactiver sans les supprimer

sleep 2; chronyc makestep || true
