Les tests, et ce qu'ils ont donné

Les tests de 09-Tests, plus ceux que l'énoncé demande de démontrer. Pour chacun : OK ou KO, et ce que tu as obtenu (une valeur, un message). Sur le serveur du labo, chaque résultat est commun au groupe, avec ton nom et l'heure ; outils/reprendre_suivi.py le recopie dans le rapport des tests du livrable (énoncé §13).

Une preuve par test

Garde une capture de chaque test réussi (Ctrl+² sur le poste de cours) : le rapport synthétique des tests est un livrable, et la soutenance demande de montrer les résultats.
