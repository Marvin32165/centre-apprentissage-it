Mémoire des VM et nomenclature : justifications (§10.1)

Mémoire statique ou dynamique (relevé du 03/11/2026 : statique sur toutes les VM)

| VM | RAM | Justification | |---|---|---| | PAR-SQL01 | 8 Go (SQL : max server memory 5 120 Mo) | SQL Server gère lui-même son cache ; la mémoire dynamique perturbe cette gestion. Mémoire statique recommandée pour SQL Server | | PAR-SP01 | 12 Go | SharePoint consomme beaucoup de mémoire au démarrage (IIS, recherche, cache) ; le guide SharePoint demande 12 à 16 Go fixes | | EXCHANGE | 16 Go | imposé par l'énoncé (§6.3) ; Exchange dimensionne ses caches à la RAM présente | | DC-PARIS, DC-BXL | 8 Go et 4 Go | contrôleurs : base AD en mémoire ; la charge est constante | | IIS01, IIS02 | 4 Go chacune | deux nœuds NLB identiques ; mémoire fixe pour un comportement comparable | | OPNsense, Docker (Zabbix, Redmine, Wazuh, Greenbone), postes Windows 11 | 4 à 8 Go | charge prévisible ; évite le gonflement de mémoire d'un conteneur au détriment des autres VM | Le total alloué par hôte reste inférieur aux 64 Go (Paris 40 Go actives, Bruxelles 40 Go, Londres 16 Go, Berlin 24 Go), il n'y a donc pas besoin de surallouer. Réserve : DC-PARIS est à 12 vCPU / 8 Go (le plan prévoyait 2 vCPU / 4 Go) ; à réduire avant la remise si la charge le permet.

Nomenclature

  • Machines : <SITE>-<RÔLE><NN> en majuscules (PAR-DC01, PAR-SQL01, PAR-SP01, PAR-CLT01, PAR-FW01). Préfixes : BRU, PAR, LON, BER.
  • vSwitch : un externe pour le WAN et un privé pour le LAN par site.
  • VHDX : un fichier <VM>.vhdx par disque, dynamique ; disques de données nommés -DATA, -LOGS, -TEMPDB (PAR-SQL01).
  • Écarts constatés (à corriger avant la remise) : VM OPNSense - Paris, DC-PARIS, 2-PARIS-UBUNTU à Paris ; DC-BXL, EXCHANGE, IIS01, IIS02, OPNsense, ZABBIX à Bruxelles ; vSwitch 2-OPNSENSE-PARIS, 2-LAN-PARIS, BXL-WAN, VS-WAN… Renommer les VM Hyper-V (le nom d'hôte Windows est déjà bon) et uniformiser les vSwitch.
  • Image de départ : disque parent SYSPREP.vhdx (Windows Server 2025 généralisé) ; fusionner les disques des VM qui en dépendent avant la remise.
