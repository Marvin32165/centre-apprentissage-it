Gabarit de module

À copier dans modules/<id>.html pour chaque nouveau module (l'en-tête de cette page est celui d'un module ; seul <head> et le contenu changent). Les étapes pour ajouter un module sont en haut de assets/modules.js.

  1. Ajouter l'entrée dans IT_MODULES.modules (assets/modules.js) : id, titre, domaine, niveau (1 à 3), duree (minutes), prerequis (identifiants de modules), resume, tags, prepa (jours de la prépa approfondis), suite.
  2. Copier cette page vers modules/<id>.html et remplacer gabarit par l'identifiant (data-module-meta, data-module-suite, data-quiz, data-done en module-<id>).
  3. Écrire le quiz dans assets/modules-quiz.js sous la clé module-<id> (6 questions, bonne réponse à des positions variées).
  4. Ajouter module-<id> dans les units de la rubrique « modules » de assets/data.js.

Trame à respecter

  • Pas de recopie de la prépa : le module approfondit et renvoie vers les jours concernés (prepa dans les données).
  • Je montre : théorie courte, une source officielle par section dans un encadré callout source ; ce qui dépend de l'UMONS dans un callout umons (« à vérifier sur place »).
  • On fait ensemble : un pas-à-pas à reproduire (VM, labo), avec « ce que tu dois constater » dans un <details class="correction">.
  • Tu fais seul : mises en situation et exercices, toutes les corrections dans des <details class="correction">.
  • Quiz (data-quiz), fiche mémo, questions pour le tuteur, case « Module terminé » (data-done) et suite (data-module-suite).
  • Rien d'inventé : une valeur, un code ou un nom que l'on ne peut pas sourcer est retiré ou marqué « à vérifier ».
